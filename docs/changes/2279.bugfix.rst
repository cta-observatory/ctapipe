``CameraGeometry.transform_to()`` now keeps all frame attributes, also when passing
a frame class, including those not used by the target frame. Previously, e.g. the
``focal_length`` was lost when transforming to ``TelescopeFrame``, so transforming
back to ``CameraFrame`` failed:

.. code-block:: python

   geom_tel = geom.transform_to(TelescopeFrame)
   geom_cam = geom_tel.transform_to(CameraFrame)  # previously failed: missing focal_length
   geom_cam.frame.focal_length == geom.frame.focal_length  # True
